About

I'm an MCA graduate working as an SQL Developer Trainee at Data Collection Info Tech in Bengaluru, where I build and optimize the backend that a nationwide pavement and road-survey data pipeline runs on — from raw distress data in MySQL and PostgreSQL to REST APIs that annotate, store, and serve it at scale.

My day-to-day spans four layers of the same stack: writing and tuning production SQL across large geospatial datasets, designing FastAPI/Flask REST APIs deployed on GCP and Ubuntu VMs, packaging PyQt5 desktop tools that field teams use for data allocation and merging, and provisioning the cloud infrastructure — Cloud Storage buckets, Compute Engine VMs, IAM — that all of it runs on.

Outside work, I'm exploring computer vision (a 30+ gesture hand-tracking controller built on MediaPipe) and building SQLFlow Pro, an open-source SQL visualization tool, alongside running a small gaming arena business with its own Firebase-backed booking site.
